# Метки triage

Скиллы оперируют пятью каноническими ролями triage. Этот файл сопоставляет роли с реальными метками в трекере задач репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                         |
| ------------------------- | --------------------- | ------------------------------------------------ |
| `needs-triage`            | `needs-triage`        | Мейнтейнеру нужно оценить задачу                 |
| `needs-info`              | `needs-info`          | Ждём от автора дополнительную информацию         |
| `ready-for-agent`         | `ready-for-agent`     | Полностью описана, готова для автономного агента |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком                     |
| `wontfix`                 | `wontfix`             | Делать не будем                                  |

Когда скилл упоминает роль (например, «поставь метку готовности для агента»), используйте соответствующую метку из таблицы.

Чтобы использовать другие названия, поменяйте столбец «Метка в нашем трекере».
