# Календарь звонков

[![hexlet-check](https://github.com/iusik/ai-for-developers-project-386/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/iusik/ai-for-developers-project-386/actions)

Простой сервис для бронирования звонков со мной — упрощённый аналог [cal.com](https://cal.com).

Любой посетитель открывает страницу, выбирает свободное время в моём календаре и бронирует звонок. Регистрация и вход не нужны.

Учебный проект Хекслета: https://ru.hexlet.io/programs/ai-for-developers

## Идея

У сервиса один владелец календаря — я. Все остальные пользователи — гости, которые хотят со мной созвониться.

Чего в проекте нет и не планируется:

- регистрации и авторизации;
- нескольких владельцев календаря и командных расписаний;
- интеграций со сторонними календарями и платёжными системами.

## Основной сценарий

1. Гость открывает страницу бронирования.
2. Выбирает дату в календаре.
3. Видит свободные слоты на этот день и выбирает подходящий.
4. Указывает имя, email и, при желании, тему звонка.
5. Подтверждает бронирование и видит страницу с деталями встречи.

После бронирования слот становится занятым, и другие гости не могут его выбрать.

## Функциональность

### Для гостя

- Просмотр доступных дат и свободных слотов.
- Бронирование слота без регистрации.
- Страница подтверждения с датой, временем и длительностью звонка.

### Для владельца

- Настройка рабочего расписания: дни недели, часы и длительность звонка.
- Просмотр списка предстоящих бронирований.

## Правила бронирования

- Слоты строятся по рабочему расписанию владельца.
- Нельзя забронировать время в прошлом.
- Нельзя забронировать уже занятый слот — два гостя не могут занять одно и то же время.
- Время показывается в часовом поясе гостя.

## Стек

- **Бэкенд:** Node.js 24, Fastify 5, TypeScript, PostgreSQL 18 (Drizzle ORM — с первой фичей, которой нужна БД)
- **Фронтенд:** React 19, Vite 8
- **Тесты:** Vitest, Testing Library; порог покрытия 80%
- **Качество:** ESLint (typescript-eslint strict), Prettier, commitlint (Conventional Commits), lefthook
- **Окружение:** Docker Compose, mise; pnpm workspaces

## Установка

Нужны только [Docker](https://www.docker.com/) и [mise](https://mise.jdx.dev).

```bash
git clone https://github.com/iusik/ai-for-developers-project-386.git
cd ai-for-developers-project-386
mise trust
mise run setup
```

## Использование

```bash
mise run dev     # db, api на http://localhost:3000, web на http://localhost:5173
mise run check   # все проверки: формат, линтер, типы, тесты с покрытием
```

Остальные команды и правила разработки — в [AGENTS.md](AGENTS.md).
