# Календарь звонков

Сервис, через который гости без регистрации бронируют звонки с единственным владельцем календаря.

## Язык

**Владелец** (`Owner`):
Единственный человек, с которым гости бронируют звонки.
_Избегать_: хост, админ, организатор, пользователь

**Гость** (`Guest`):
Посетитель, который бронирует звонок с владельцем без регистрации.
_Избегать_: клиент, пользователь, участник

**Тип звонка** (`CallType`):
Вид звонка, который предлагает владелец, со своим названием, описанием и длительностью.
_Избегать_: тип события, event type, услуга, тип встречи, шаблон
